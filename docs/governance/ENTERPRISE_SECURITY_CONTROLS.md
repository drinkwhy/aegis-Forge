# Enterprise Security Controls

This document summarizes the comprehensive security posture enforced by Aegis Crucible.

## Control Domains
- **Data Protection**: Envelope Encryption, TLS 1.3 in-transit, Data Minimization, and Redaction.
- **Identity**: Capability-based tokens, OAuth integrations, encrypted Credential Broker.
- **Compliance**: Automatic control mapping, Evidence Manifests, tamper-evident Cryptographic Ledger.
- **Infrastructure**: Zero-trust worker isolation, PostgreSQL RLS, automated retention purging.
